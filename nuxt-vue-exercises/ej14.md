## Ejercicio 14 Vue, Soluciona los errores

En estos fragmentos de código puede que encuentres algún error, solucionalos y justifica el cambio.

```vue
// composables/useCounter.ts
import { ref } from "vue";

export function useCounter() {
  const count = ref(0);

  function increment() {
    count.value++;
  }
}
```

En el primer fragmento de código faltaría hacer un return de lo que quieres exportar al final, con un return { count, increment } para exportar tanto la variable count como la función increment.

```vue
<script setup>
import { ref } from "vue";

const items = ref(["Apple", "Banana", "Cherry"]);
</script>
<template>
  <ul>
    <li v-for="(item, index) in items" :key="index">
      {{ item }}
    </li>
  </ul>
</template>
```

En este caso no seria un error como tal, pero usar el indice como key no es recomendable.

```vue
<script>
const counter = 0;
</script>
<template>
  <p v-if="counter == 10">Número, {{ counter }}</p>
</template>
```

Habria que usar el setup para trabajar con composition api y que por tanto puedas acceder desde el template a counter de esa manera.
