## Ejercicio 10, preguntas sorpresa

1. ¿Qué es un linter?
Un linter es una herramienta que te ayuda a detectar errores que configuras al descargarlo. Pueden ser simples warnings o hasta te puede evitar que hagas cualquier cosa.

2. ¿Qué es Husky?
Husky es una forma de configurar los hooks de git de manera mas sencilla y permite poder compartirlo a traves de github.

3. ¿Qué es la reactividad?
La reactividad son los datos que pueden cambiar en los componentes de los frameworks a traves de javascript o typescript permitiéndote usar datos dinámicos.

4. ¿Desde dónde hay que crear todas las ramas para los desarrollos?
Desde la rama main.

5. ¿Cuándo se puede utilizar la rama main?
En ningún caso se programa en la rama main, solo se hacen pr de otras ramas con funcionalidades que funcionan correctamente.

6. ¿Qué son las custom properties?
Son como las variables de css, pues se definen en el :root y te permite reutilizarlas.

7. Diferencias entre v-if y v-show
La directiva v-if si no se cumple la condición no existe en la pagina web, pero el v-show si no se cumple la condición la etiqueta se queda con un display none oculta, pero sigue existiendo en la pagina web.

8. ¿Cuáles son los valores de falsy?
Los valores falsy son los que independientemente de su tipo se consideran vacíos tales como 0, '', null, undefined, -0, 0n y NaN.

9. ¿Qué es Nullish Coalescing Operator?
Es un operador que te permite asignar a un dato un valor por defecto en caso de que no recibiera datos, en este caso con el Nullish Coalescing Operator evalúa un valor nullish, es decir null o undefined

10. ¿Para que se utiliza TypeScript?
Para tener más control y seguridad respecto a javascript ya que permite tipos, y tiene un tipado estático es decir que tienes que especificar el tipo de dato que se usa y un tipado fuerte que no permite reasignar a un diferente tipo.
